# DOCX

The tool extracts raw paragraph text. Images, complex tables, and tracked changes are not preserved.

- Use the extract as the document body.
- If tables collapse into a text stream, say so instead of pretending the grid is intact.
- Do not write a .docx back. Save follow-up notes as Markdown.
